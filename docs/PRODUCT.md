# JUHYU — 알바비, 제대로 받고 있나요?

주휴수당 계산기 → 알바 급여 계산기 → **알바 급여 검증 도구**로 포지셔닝을 바꾼 기록.

## 1. 기존 프로젝트 분석 (2026-09-30)

| 항목 | 상태 |
| --- | --- |
| 프레임워크 | React 18 + Vite 5, 단일 `src/App.jsx`(1,300줄) SPA |
| 라우팅 | 없음. `/` 한 URL 안에서 탭(주휴수당·퇴직금·공부방) 전환 |
| 계산 로직 | 주휴수당(시급 × min(주시간,40)/40 × 8, 15시간·개근 조건), 투잡 합산, 퇴직금 |
| 저장 | localStorage: `juhyu-calc-v1`, `juhyu-calc-job2-v1`, `juhyu-receipt-log-v1`, `juhyu-severance-calc-v1` |
| SEO | 메타·canonical(`/`)·google-site-verification, JSON-LD는 JS로 주입, 본문은 JS 실행 전 빈 화면 |
| sitemap/robots | `/` 한 개, robots는 전체 허용 |
| 광고 | AdSense 스크립트(head) + 빈 "광고 영역" 박스가 계산기 위에 노출 |
| 콘텐츠 | 공부방 글 29개 (주휴 조건·결근·신고·급여명세서 등) |

## 2. 유지 / 수정 / 제거

- **유지**: 주휴수당 계산식과 판정 문구, 투잡 합산, 영수증철, 사장님께 보낼 메시지, 퇴직금 계산, 공부방 글 전부, 기존 localStorage 키(그대로 읽고 씀), `/` URL과 canonical, AdSense·사이트 인증 메타, ads.txt, robots.txt
- **수정**: 단일 파일 → 모듈 분리, 인라인 스타일 → 디자인 토큰 CSS, 공부방 글 중 단정적 표현·낡은 UI 안내 수정, 2027 최저임금 반영
- **제거**: 계산기 위의 빈 광고 자리(슬롯 ID가 있을 때만 광고 렌더링), JS로 주입하던 JSON-LD(정적 HTML로 대체)

## 4. 기술 구조

```
src/lib/legal.js      법정 기준값(최저임금·4대보험 요율·조문) + 출처·확인일 — 숫자는 여기서만 관리
src/lib/pay.js        계산 엔진(순수 함수): 근무시간·야간시간·주휴·가산·공제·검증
src/lib/payslip.js    명세서 텍스트 파서 + 명세서 검산/비교 (향후 OCR 결과 텍스트도 같은 입력)
src/lib/usePayInput.js 공유 입력 상태(localStorage `juhyu-pay-v2`) — 계산기·검증·명세서·월 페이지가 공유
src/components/        UI 조각, PayCalculator(변형: full / monthly / verify)
src/pages/             페이지별 컴포넌트 + `faq` export(본문과 FAQPage JSON-LD가 같은 데이터 사용)
src/site.js            URL·타이틀·디스크립션
scripts/prerender.mjs  빌드 후 모든 페이지를 정적 HTML로 렌더링 + sitemap.xml 생성
tests/                 계산 엔진·파서 회귀 테스트 (`npm test`)
```

- **정적 프리렌더(SSG)**: `npm run build`가 페이지마다 `dist/<경로>/index.html`을 만든다. 본문·title·description·canonical·OG·JSON-LD가 HTML에 들어가 JS를 실행하지 않는 크롤러(네이버 등)도 내용을 읽는다. 브라우저에서는 같은 컴포넌트로 hydrate.
- **코드 분할**: 페이지별 청크 + modulepreload. 공통 JS 약 51KB(gzip).
- **배포**: 빌드 명령 `npm run build`, 출력 폴더 `dist`. 정식 URL은 끝에 `/`가 붙은 형태. 없는 경로는 `404.html`.
- **개인정보**: 서버·DB 없음. 입력값은 브라우저 localStorage에만 저장.

## 5. 계산 기준 (확인일 2026-09-30)

- 최저임금: 2026년 10,320원, 2027년 10,700원 (고용노동부 고시)
- 주휴수당: 주 소정근로 15시간 이상 + 개근 → 시급 × min(주시간, 40) ÷ 40 × 8 (근로기준법 제55조, 시행령 제30조, 제18조 제3항)
- 야간(22~06시)·연장(1일 8시간·주 40시간 초과) 가산 50%: 상시 5인 이상 (제56조, 시행령 제7조 별표1). 사업장 규모 "잘 모름"이면 합계에서 빼고 "5인 이상이면 +X원"으로 별도 표시
- 휴게시간: 무급, 야간 계산 시 주간·야간 비율로 차감 (휴게 시각을 알 수 없으므로)
- 4대보험 근로자 부담(2026): 국민연금 4.75%, 건강 3.595%, 장기요양 = 건강보험료 × 13.14%, 고용 0.9%, 10원 미만 절사. 근로소득세(간이세액표)는 계산하지 않음
- 3.3%: 소득세 3% + 지방소득세(소득세의 10%)
- 월 계산: 선택한 달의 실제 달력. 주는 월~일, 일요일이 속한 달에 그 주 주휴수당 포함. 공휴일은 미반영(결과에 안내)

## 6. 매년 해야 할 일

1. `src/lib/legal.js` — 다음 해 최저임금 추가, `CURRENT_YEAR` 갱신(1월 1일), 4대보험 요율·확인일 갱신
2. `src/site.js` — `updated` 날짜, 페이지 title의 연도
3. `npm test`로 계산 회귀 확인 후 배포

## 8. 알바비 추적 (월급 탐정) — 2026-09-30 추가

계산기 → **기록 → 검증 → 발견 → 정산** 흐름을 한 페이지(`/tracker/`)에 만들었다.

| 해시 경로 | 화면 |
| --- | --- |
| `#/start`, `#/setup` | 3단계 시작(알바 정보 → 근무 조건 → 완료) |
| (기본) | 대시보드: 이번 달 일한 시간·예상 금액·받은 금액·차이, 기록 달력, 확인할 항목 |
| `#/log/YYYY-MM-DD` | 근무 기록(평소 시간 자동 채움, 실근무시간·예상 임금 즉시 표시, 메모·사진) |
| `#/pay/YYYY-MM` | 받은 급여 입력(입금일·금액·몇 월분·세전/통장 기준) |
| `#/issues/YYYY-MM` | 차이 상세: 예상 내역, 확인해볼 항목, 기록 점검 |
| `#/payslip/YYYY-MM` | 급여명세서 ↔ 내 기록 항목별 비교(일치/확인 필요) |
| `#/timeline` | 근무 기록 타임라인(기록·수정 시각 포함) |
| `#/message/YYYY-MM` | 중립적인 급여 확인 메시지 |
| `#/report/YYYY-MM` | 월말 리포트(프린트/공유) |
| `#/settle` | 퇴사 전 알바비 정산 리포트 |
| `#/settings`, `#/edit` | 알바 정보 수정, 알바 추가, JSON 백업/복원, 삭제 |

- **계산 재사용**: `pay.js`의 `summarizePay`를 스케줄 계산기(`calculatePay`)와 기록 기반 계산(`calculateLogged`)이 함께 쓴다. 하루 금액은 `logAmounts`.
- **저장**: `localStorage['juhyu-tracker-v1']` = `{ version, activeId, workplaces[], logs[], payments[], payslips[] }`, 사진은 `juhyu-photo-<logId>`(900px JPEG로 줄여 저장). 기존 키는 건드리지 않는다.
- **확인 항목 찾기(`detectIssues`)**: 차이 금액이 특정 날짜 근무·주휴(한 주분/월 전체)·공제·3.3%·시급 N시간분과 비슷한지, 22시 이후/8시간 초과 기록, 기록이 빠진 근무 예정일, 짧은 휴게, 주 15시간 근처인 주, 최저임금 미만 시급. 표현은 "차이가 있습니다 / 확인해보세요"까지만.
- **주휴 규칙**: 월~일 한 주, 일요일이 속한 달에 포함(스케줄 계산기와 동일). 기록 기반이라 결근·소정근로시간은 알 수 없어 설명에 명시.
- 테스트: `tests/tracker.test.mjs`
